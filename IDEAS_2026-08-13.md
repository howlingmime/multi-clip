# Extension Ideas — 2026-08-13

## Vision
Evolve MultiClip from a rolling 50-item text buffer into a keyboard-first, privacy-respecting clipboard workbench for macOS: rich-content aware, scriptable, searchable, and — when the user opts in — smart enough to suggest the exact snippet you were about to paste, without ever leaving the machine.

## Text-First Features
- **Rich Content Types** — Preserve RTF, HTML, image, file-URL, and color pasteboard flavors; picker shows a type badge per clip and pastes with the original type.
- **Full-Text Search in Picker** — Live filter across the last N clips with fuzzy matching, tokenized by word and file path.
- **Persistent History with SQLite Backing** — Optional on-disk store (encrypted with a user-supplied passphrase via Keychain) that survives reboots and grows past 50.
- **Named Snippets ("Pinned Clips")** — Right-click any clip to promote to a permanent, named snippet accessible via a sub-palette.

## UX & Design
- **Reorderable Selection** — Drag numbered badges to reorder chosen clips before pasting; keyboard arrows also reorder.
- **Separator Presets** — Save common separators (comma, `\n\n`, `, `, ` | `) as one-key options in the picker footer.
- **Inline Preview Pane** — Hovering a clip shows a full preview (wrapped text, image thumbnail, file path with icon) on the right side of the picker.

## Content & Data
- **Per-App Rules** — "Never capture from 1Password / Bitwarden / password managers"; auto-purge clips that look like credentials via regex heuristics.
- **Transform Pipeline** — Apply chained transforms before paste: trim, lowercase, url-decode, remove smart quotes, wrap-in-markdown-code, base64-decode.
- **Timestamped Export Formats** — Export history as Markdown, JSON, or CSV with capture-time and source-app metadata.

## Platform & Distribution
- **Signed and Notarized `.app` Bundle** — Ship a proper `.app` with `LSUIElement=true`, Sparkle auto-update, and a Homebrew Cask formula.
- **iCloud Handoff (opt-in)** — Sync the last 20 clips to a companion iOS share-sheet extension via CloudKit, end-to-end encrypted.
- **CLI Companion (`mcp`)** — `mcp list`, `mcp get 3`, `mcp push "text"`, `mcp pipe` for tapping the history from shell scripts.

## AI & Automation
- **On-Device Semantic Search** — Embed clips with a local Core ML model so "the address I copied last Tuesday" finds it even without exact words.
- **AppleScript / Shortcuts Actions** — Expose "Get Clip N", "Paste Chosen Clips", "Clear History" as Shortcuts + AppleScript verbs.
- **Smart Paste Suggestions** — Foreground-app + surrounding-context heuristic ranks the top 3 likely clips at the top of the picker.
- **Auto-Format on Paste** — Detect destination (Slack, Terminal, code editor via bundle ID) and pick the right flavor and separator automatically.
